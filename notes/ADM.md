# ADM — заметки практики

> **Что здесь:** проверенные практикой правила и грабли сервиса ADM (пользователи, роли, тенант). Сигнатуры ручек — [endpoints/ADM.md](../endpoints/ADM.md).
> **Когда сюда идти:** перед выборкой пользователей через API.

## Грабли

⚠ `GET /Users/short`: повторённый `roleID` (`roleID=3&roleID=33`) — **объединение** (ИЛИ): 9 + 4 − 1 общий = 12; `roleID` вместе с `districtID` — **пересечение** (И). Без `roleID` фильтра по роли нет — отдаются все пользователи; пустой набор ролей поэтому означает «все», и вызывающий сам должен не слать запрос без ролей. Ответ — словарь «`userID` → пользователь», ключ совпадает с `userID` в теле; `206` с `Content-Range` (2026-11-10, тенант 55, с `isBanned=false&isDeleted=false`). Включает ли `districtID` пользователей вложенных участков — не проверялось.
